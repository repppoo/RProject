WHAT HAPPENED?

Let’s place the first order.

  1. Click “Place an order” to reserve four meals and update the totals.
Why this helps the team

The team can see what needs attention without manually checking every order.

Where could AI help? It could read a customer’s written request and suggest the order details. Clear rules still check prices and stock, and a person reviews anything uncertain. This demo uses rules, not AI.

How it works — for a technical conversation

The demo checks the order ID to avoid processing the same order twice, checks available stock, and updates the displayed totals. Everything stays in this page and resets on refresh.

A live version would need a database, verified incoming requests, safe stock updates when orders arrive together, and notifications with retries. Payment confirmation would be a separate step.

04 / HOW I WOULD START

Listen first.
Build something useful.

I’d start by understanding your team’s work.
Then choose one improvement we can test together.

FIRST MONTH

Understand the work

Talk to the people doing the tasks. Find out where time is lost, what tools they use, and what a good result would look like.

Agree on one problem worth solving.
SECOND MONTH

Try a small solution

Build a first version and test it with the team. Check what happens when information is missing or something goes wrong.

Use real feedback to improve it.
THIRD MONTH

Make it work day to day

Help people use it, write simple instructions, and check whether it saves time and reduces mistakes.

Expand only when it proves useful.
How I’d approach a company website

Help people find it

Use clear page titles, helpful information and pages that work well on phones. Make it easy to find answers about products and services.

Make the next step easy

Help visitors enquire or order without confusion. Check where people get stuck and improve one step at a time.

Check whether it helps

Measure useful actions, such as completed enquiries and purchases, instead of looking only at visitor numbers.

Tools I would learn or use as appropriate: Google Analytics 4 for visitor behaviour, Tag Manager for measurement tags, and Search Console for search visibility. This is a proposed approach; these tools are not installed on this portfolio.

How I’d keep a system safe and reliable

Give people only the access they need. Protect passwords and confidential data. Keep backups and check that they can be restored. Make errors visible, assign someone to respond, and keep a manual backup process.

These are practices for a live system. The sample order demo has no login, live database or backup service.
